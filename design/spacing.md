# 간격 기준 및 점검 기록

2026-09-19 기준. 기존 배치와 카드 밀도를 유지하면서 같은 역할의 간격을 공통 CSS 변수로 묶었다. 원본은 `templates/assets/style.css`이며 `scripts/build_html.py`가 배포용 `docs/`에 반영한다.

## 공통 기준

### 표와 모달 제목 행 (2026-09-20)

- 전적·상대전적·분석·방송통계·전적 모달의 목록 표는 `.stat-table`을 공유한다. 헤더와 본문은 20px 줄 높이와 세로 가운데 정렬을 사용하고 기존 반응형 셀 패딩을 유지한다.
- 방송통계 순위 숫자는 별도 박스 없이 표의 글자 크기와 줄 높이를 따른다. 데이터 행만 키우던 고정 크기·배치 스타일은 제거하고 색상·굵기만 유지한다.
- 세트 상세표·프로필 정보표는 목록 표와 역할이 달라 기존 밀도를 유지한다. 펼친 상세 행·로딩 안내·모바일의 두 줄 정보는 내용에 따라 높이가 늘어난다.
- 모달 제목 행은 최소 52px, 좌우 56px 여백으로 중앙 제목과 32px 닫기 버튼 영역을 분리한다. 긴 제목은 줄바꿈한다.
- 1280·768·390·360px에서 실제 전적 표 마크업과 방송통계 대표 행을 브라우저로 비교했다. 공통 표 헤더/본문 높이 차이는 경계선 병합에 따른 0.5px 이내이며, 모달 제목과 닫기 버튼의 겹침도 확인했다.

## 상대전적 검색·선택 상태

선수 선택 영역 안에서는 요약 카드 자체의 아래 여백을 없애고 부모가 간격을 담당한다. 카드 자체 여백과 부모 바깥 여백이 중복되던 문제를 정리했다.

- 모바일 PLAYER 1 검색창 또는 선택 카드 → VS: 모두 24px.
- 마지막 선수 검색창 또는 선택 카드 → 결과 영역: 24px.
- 분석 검색창 → 결과 영역: 24px.
- 모바일 첫 선수 칸에 16px, 행 간격에 8px을 적용한다. 마지막 선수 칸에는 별도 아래 여백이 없다.

## 점검 범위와 유지한 예외

공용 CSS 전체의 margin/padding/gap과 반응형 재정의, 페이지·공용 템플릿의 인라인 및 Bootstrap 간격 클래스, 관리자·독립 멀티뷰어·라이더·404의 자체 CSS를 조사했다. 브라우저 CSS 파서로 추출한 전체 목록은 `build/spacing-inventory.json`에 남긴다. CSSOM은 축약 속성을 상하좌우 속성으로 확장하므로 이 목록의 항목 수는 원본 선언 줄 수와 다르다.

다음 값은 기능이나 시각적 정렬이 다른 영역이라 유지했다.

- 페이지 히어로, 고정 상단바, 스크롤 보정, 달력 셀, 캡처 영역의 치수.
- 표의 조밀한 셀 패딩, 배지와 아이콘의 광학 보정, 칩의 글자 폭 보정.
- 티어 묶음의 종전 위아래 여백과 마진 병합 동작.
- 멤버/도구 격자 14px과 방송/티어 격자 12px의 밀도 차이.
- 공지 목록에 붙는 더 보기의 8px 연결 간격.
- 라이더 게임 화면·오버레이의 자체 배치 및 404 독립 화면.

## 검증

빌드 후 홈·일정·멤버·전적·티어·영상·방송통계·도구, 티어의 상대전적·분석까지 10개 화면을 1280/768/390px에서 비교했다. 30개 조합에서 가로 넘침이나 JavaScript 페이지 오류가 없었다. 상대전적의 선택 전/후 VS 간격은 24px, 상대전적·분석 검색 영역과 결과 사이도 24px로 실측했다.

상대전적은 추가로 360/390/767/768/920/921/1280px, 라이트/다크, 미선택/한 명 선택/두 명 선택의 42개 조합을 점검했다. 저장된 선수 데이터로 실제 카드 마크업을 렌더링하여 PC의 검색창·선수 카드·VS 세로 중심선 오차가 1px 미만임을 확인했다. 모바일의 첫 선수와 VS 간격, 모든 상태의 결과 영역 간격은 24px이며 가로 넘침은 없었다.

검증은 저장소의 로컬 데이터와 Bootstrap CSS를 사용했다. 외부 방송 API와 원격 이미지 요청은 차단했으므로 실시간 방송 데이터의 정확성이나 원격 서비스 가용성을 검사한 것은 아니다. 주요 화면의 수정 전/후 스크린샷, 측정 JSON, 임시 점검 스크립트는 `build/spacing-*`와 `build/check-spacing.cjs`에 있다. `build/`는 Git 추적 대상이 아니다.
